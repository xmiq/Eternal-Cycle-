# Support and Feedback

This family defines release-neutral, privacy-conscious support routing for Eternal Cycle rules and tooling.

## Reading Order

1. [Community Feedback and Diagnostics](COMMUNITY_FEEDBACK_AND_DIAGNOSTICS.md) - classification, sanitized diagnostics, issue-report assistance, and feedback lifecycle.
2. [Official Support Metadata](../../SUPPORT.md) - authoritative project and issue destinations for this distribution.

Campaign outcomes, questions, ambiguities, engine defects, reference-tooling defects, and third-party implementation defects remain distinct. No document in this family authorizes silent external submission or disclosure of Campaign Canon.
