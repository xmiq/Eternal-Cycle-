## GM Framework

- [GM Principles](gm/GM_PRINCIPLES.md) - system-first adjudication, fair uncertainty, meaningful death, and contextual capability judgments.

## Authority and Scope

Canonical rules and design governance have different responsibilities. Rules under `docs/` must remain consistent with accepted decisions in [Design Decisions](../design/DECISIONS.md); neither source silently overrides the other. Any conflict must be resolved in both places before the affected material is complete.

This repository contains reusable rules, governance, templates, and GM guidance only. Campaign saves, current characters, live world state, inventories, active quests, story summaries, and playthrough history belong outside it.
