# Skill Engine

The Skill Engine defines how bounded learned capabilities are structured, related, translated, transformed, expressed, discovered, and represented without creating a universal character level or Skill currency.

## Shared Skill Model

Every canonical Skill claim must keep these dimensions distinct:

| Dimension | Question |
| --- | --- |
| **Skill Identity** | What bounded learned capability does the Skill actually represent? |
| **Origin** | Is its route human, monster, shared, profession-derived, species-derived, magical, social, conceptual, or otherwise established? |
| **Requirements** | Which body, senses, knowledge, tools, environment, authority, relationships, or metaphysical conditions are necessary? |
| **Persistent Familiarity** | What Skill XP, Skill Imprint, or learning advantage legitimately persists? |
| **Current Access** | What can the present incarnation recall, reconstruct, interpret, or invoke now? |
| **Embodied Expression** | What can the current body and receiving system actually perform? |
| **Practised Reliability** | What remains dependable under pressure, fatigue, variation, and disruption? |
| **Contextual Effectiveness** | How useful is the capability for the present objective, environment, opposition, tools, and allies? |
| **Evolution State** | Has the Skill refined, specialised, broadened, compressed, translated, fused, or conceptually transformed through a valid rule? |
| **Visibility** | Who knows, recognises, conceals, misidentifies, or only partly understands the Skill? |

These dimensions form a qualitative record, not a score. High Persistent Familiarity does not guarantee Current Access; Current Access does not guarantee Embodied Expression; reliable expression may still be a poor contextual match.

## Canonical Documents

1. [Human Skill Trees](HUMAN_SKILL_TREES.md) - plural human learning structures shaped by culture, practice, embodiment, tools, professions, and institutions.
2. [Monster Skill Trees](MONSTER_SKILL_TREES.md) - monster-native learning structures shaped by species embodiment, ecology, cognition, social transmission, and individual experience.
3. [Reincarnation Skill Crossover](REINCARNATION_SKILL_CROSSOVER.md) - bounded recovery and translation of retained Skill history through valid present-life receiving routes.
4. [Adaptive Skills](ADAPTIVE_SKILLS.md) - emergence of stable novel capabilities through recurring need, variation, feedback, adjustment, and integration.
5. [Skill Evolution](SKILL_EVOLUTION.md) - qualitative transformation of established capabilities through route-specific patterns, evidence, and tradeoffs.
6. [Skill Fusion](SKILL_FUSION.md) - formation of a distinct bounded competency through sustained integration of established Component Skills.
7. [Active and Passive Skills](ACTIVE_AND_PASSIVE_SKILLS.md) - active, passive, and mixed expression modes with capacity, disruption, and agency rules.
8. [Hidden Skills](HIDDEN_SKILLS.md) - observer-relative hiddenness, fair evidence, discovery, misclassification, concealment, and agency rules.
9. [Conceptual Skills](CONCEPTUAL_SKILLS.md) - bounded advanced competencies operating through deeply integrated principles, relationships, meanings, and metaphysical concepts.
10. [Skill Engine Safeguards](SKILL_ENGINE_SAFEGUARDS.md) - unified capability classification, ownership tests, anti-proliferation rules, and representation cleanup.

All ten Phase 3 rule documents are now present. The [Roadmap](../../design/ROADMAP.md) remains authoritative while their integration audit is completed.

## Foundations

- [Skill Development](../progression/SKILL_DEVELOPMENT.md) owns acquisition, Skill XP, Skill Imprints, mastery evidence, relearning, and shared Development boundaries.
- [Development Interactions](../progression/DEVELOPMENT_INTERACTIONS.md) owns effect ownership, dependency, support, and no-duplicate-benefit resolution.
- [Capability Assessment](../progression/CAPABILITY_ASSESSMENT.md) owns scoped comparison, evidence, uncertainty, and observer views.
- [Development Safeguards](../progression/DEVELOPMENT_SAFEGUARDS.md) owns shared anti-grinding, anti-farming, agency, and embodiment protection.
- [Reincarnation](../soul/REINCARNATION.md), [Soul Echoes](../soul/SOUL_ECHOES.md), and [Retained Instincts](../soul/RETAINED_INSTINCTS.md) govern persistent history and access without granting present mastery.

## Boundaries

Skill Engine documents may define Skill structures and transformations. They do not silently create species traits, biological evolution, professions, institutional authority, relationships, equipment, magical sources, Soul effects, or a universal progression interface. Each claimed effect retains one Owning System.
