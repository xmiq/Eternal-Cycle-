# Level 0 Instinct
## Purpose

This document defines Level 0 as the existing Skill system's representation of instinctive access. It applies to species instinct, Evolution-granted access, and inherited lineage aptitude without creating a separate Skill Seed system.

## Core Rule

**Level 0 Instinct** means a Skill exists in an individual's Skill tracking as an instinctive affinity or pattern familiarity but has not reached ordinary Level 1 capability.

Level 0 is a local Skill label, not a universal character level, rank ladder, or claim that every Skill uses numbered levels.

## What Level 0 Can Represent

A Skill at Level 0 may support only effects explicitly defined for that Skill, such as:

- attention toward relevant cues;
- primitive or reflexive expression;
- intuition or pattern recognition;
- behavioral tendency;
- error sensitivity;
- a valid receiving route for later learning;
- accelerated early learning under existing Development rules.

If a Skill defines no bounded Level 0 expression, Level 0 supplies affinity and a tracked learning route but no reliable active capability.

## What Level 0 Does Not Grant

Level 0 does not grant:

- normal Level 1 capability;
- Skill XP, mastery, Practised Reliability, judgement, or conscious technique;
- memories, instruction, accomplishments, or another person's expertise;
- anatomy, Mana Access, authority, tools, environmental support, or permission;
- exemption from embodiment, feedback, training, cost, failure, or counterplay.

It is not an inactive or fake Skill. It is real instinct represented within the Skill system, with deliberately bounded expression.

## Origins

A Level 0 Instinct needs explicit provenance, such as:

- current species architecture;
- an Evolved Form;
- a valid inherited outcome under [Lineage and Evolutionary Inheritance](../gm-living-codex/LINEAGE_AND_EVOLUTIONARY_INHERITANCE.md);
- a bounded Mutation or other specialist rule that explicitly grants instinctive Skill access.

Similarity, desire, exposure, ancestry alone, or a parent's mastery cannot create Level 0.

Prior-life [Familiarity Unlock](../progression/RETAINED_CROSS_LIFE_DEVELOPMENT.md#familiarity-unlock) is not automatically Level 0. If no explicit Level 0 provenance and valid receiving route exist, historical familiarity remains in retained Skill provenance rather than becoming an inactive Skill seed.

## Development

Level 0 may make initial learning more efficient because the individual has a valid receiving route and useful feedback. Advancement still requires meaningful current-life use, instruction, experimentation, adaptation, and demonstrated reliability under [Skill Development](../progression/SKILL_DEVELOPMENT.md).

When the local Skill's evidence supports ordinary Level 1 capability, update the same Skill record. Do not create a second learned copy or convert a hidden seed object.

Regression from developed capability is not automatically Level 0. Rust, suppression, injury, inaccessible mastery, and embodiment mismatch retain their existing Development owners.

## Evolution-Linked Inheritance

An inheritance outcome may grant Level 0 access to an Evolution Skill without granting the ancestral Evolved Form. The current body must still support any expression claimed. A wing-control instinct in a wingless body may shape spatial intuition or learning only if the Skill defines such translation; it cannot create wings or flight.

## Inspection and Knowledge

Level 0 exists in authoritative Skill tracking so hereditary instinct is not hidden in a parallel subsystem. Whether a character or player can inspect, name, or understand it follows Campaign Knowledge and interface rules. Authoritative tracking does not make the fact public.

## Safeguards

- No separate Skill Seed subsystem.
- No inherited mastery, XP, memories, or normal Level 1 capability.
- No universal Level 0 effect shared by all Skills.
- No automatic promotion through time, repetition, lineage prestige, or parental power.
- No duplicated Skill record when Level 0 develops further.
- No bypass of human/monster tree ownership or Reincarnation crossover.
