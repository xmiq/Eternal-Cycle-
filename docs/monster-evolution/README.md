# Monster Evolution Rules

Monster Evolution describes how monster forms, populations, and societies respond to ecology, embodiment, meaningful pressure, and world change without using universal levels, kill counts, rarity tiers, or mandatory evolution trees.

## Available Rules

- [Monster Ecology](MONSTER_ECOLOGY.md) - niches, resource webs, ecological relationships, carrying capacity, territory, migration, reproduction, competition, and extinction pressure.

## Boundary

These documents define reusable canonical rules. They contain no species catalog, named population, current ecology, campaign creature, settlement, faction, or live world state.
