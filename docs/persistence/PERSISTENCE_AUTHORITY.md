# Persistence Authority

## Executable Authority

### Authority Is Claim-Specific

**E01 Claim authority.**
For incompatible claims of the same subject/property/scope/time: Repository Canon > Campaign Canon > Historical Record > Current Campaign State > Current Session > Current Narration. Compare claims, not document prestige. Lower cannot silently replace higher; use authorized correction/retcon/migration. Recency/repetition/drama/storage location/momentary acceptance confer no authority. Distinct claims retain their E02-E08 owners: valid new recovery integrates history/state, never erases established loss.

### E02 Repository and rules
Repository Canon owns reusable mechanics and accepted governance: playable docs/accepted decisions/terminology/owners-scopes/safeguards/completed foundations, never populated campaign facts. Rule-status differs from fact authority: higher persistence cannot invent mechanics; lower rule status cannot rewrite facts; both must be valid. Conflicting playable rules/governance: neither wins silently; resolve both under Repository Conventions before declaring affected material complete.

### E03 Campaign premises
Campaign Canon is highest campaign-specific authority permitted by Repository Canon: identity/continuity, adopted revision/profile, approved optional premises, setting foundations, participant/control agreements, retcon scope, permitted interpretations, conversions, stable IDs. Permitted options, clearly external experiments or older profiles do not canonize incompatible mechanics. Changes require authorized campaign decisions with provenance/scope/date/affected records/migration consequences; narration, GM preference, player theory, repeated error or file edits cannot authorize them. Recorded profile interprets prior outcomes until explicit conversion, subject to mandatory safety/owner-approved correction. Updates never silently rewrite history.

### E04 History
Historical Record durably orders established events/transitions/discoveries/corrections/consequences: what/when/where, actors/systems, supporting sources/adjudication, changes, unresolved matters, supersession. Append normally; ended effects do not erase events. Corrections preserve traceable old accounts/supersession; retcons record Campaign Canon action before propagation. Dated testimony/belief/research/narration retain information status, not automatic fact.

### E05 Current state
Current Campaign State is latest authoritative structured now within its scopes, derived from Campaign Canon/history. Bodies/Soul/relationships/placement/possessions/institutions/projects/research/world conditions/unresolved processes use Structured Persistence Architecture/Campaign State Model owners. Material consequences change only by valid new event/correction/retcon/migration. Repair stale/missed updates from authoritative history/source adjudication; never erase later history. State outranks informal memory/narration for integrated conditions, not valid unintegrated session events: those remain pending.

### E06 Session
Current Session contains bounded facts/resolved outcomes/player decisions/adjudication traces/deltas/uncertainties since confirmed integration. Valid resolved change is not proposal/draft/plan/hypothetical/uncommitted branch. Session cannot amend Campaign/Repository Canon. Classify contradictions before integration; incomplete recording requires recovery, not discarding events. Save Update Protocol integrates confirmed changes into history/state. Keep Session Delta identifiable until atomic activation, neither draft nor validated Save Point. Numerical changes require an owned event or explicit correction.

### E07 Narration
Current Narration presents scenes/sensations/dialogue/descriptions/summaries/inferred continuity, at lowest persistence authority. Ordinary detail needs GM authority/no higher conflict; newly adjudicated events may be faithfully presented. Incomplete/observer-limited/metaphorical/mistaken/ambiguous/stale/trace-contradicted/inconsistent presentation gains no authority. Stop conflicting prose; use Continuity Resolution. Never defend/compound known error or invent hidden recovery to defend prose.

### E08 Codex and owners
GM Living Codex is reusable design below Repository Canon, not a campaign Truth Layer. Configuration records adopted Codex Version; Campaign Canon owns presence/divergences. Later revisions never silently migrate/overwrite campaigns. Mechanics/adopted premises/events/integrated now/pending interaction/audience presentation retain E02/E03/E04/E05/E06/E07 owners respectively.

### E09 Visibility
Every layer may hold restricted GM guidance/setup/events/state/session notes. Narration reveals only an Observer View. Truth Layers owns access/disclosure; authority rank does not. GM access/secrecy grants neither Character Knowledge nor stronger factual authority.

### E10 Certainty
Unknown, Not Yet Verified, Estimated, Disputed, Requires Source Recovery and Pending Resolution are valid authoritative statuses. Preserve them at every layer; unsupported certainty/lower guesses cannot replace higher unknowns. Belief/theory/estimate remain distinct from fact.

### E11 Agency
Records preserve prior statements/obligations/plans/beliefs/pressures/choices/conditions, not future deliberate choices or scripts. Relationships cannot compel affection/obedience; faction plans cannot guarantee execution; prophecies do not own future events; Soul Titles cannot compel conduct; recorded player objectives never authorize GM selection of the character's next action.

### E12 Integration
Owning procedures govern downward change: repository migration reinterprets fields; retcon changes declared history/state; valid history updates state; integrated sessions append history/update state; state grounds narration. Record source/scope/affected records/unresolved conflicts; never silently overwrite. Before adoption/retcon/upward change, stop that branch; obtain complete Authority Governance/owning procedures. Higher changes require their own authority process.

### E13 Conflict
For apparent incompatibility, in order: (1) exact subject/property/scope/time; (2) both claim layers, not whole file/transcript; (3) establishing/constraining specialist owner; (4) chronology/region/observer/meaning; (5) fact/proposal/belief/theory/estimate/secret/narration status; (6) preserve higher, stop lower propagation; (7) classify narration error/stale state/incomplete save/corruption/source gap/authorized retcon/rules migration/in-world deception; (8) owning correction/migration/save/continuity procedure; (9) record change/reason/authorizer/dependent review; (10) resume coherently. Unaffected play may continue; disputed claims remain unsettled until resolved. Obtain material specialist procedures before executing them; if absent, stop affected action, never guess.

### E15 Limits
Authority owns precedence/conflict routing, not full modular architecture, Truth Layer ownership/visibility, persistence lifetimes, schemas, migration stages, full Continuity Resolution, save transactions, validators or templates. Dedicated owners govern these; blank templates implement contracts without gaining authority.
