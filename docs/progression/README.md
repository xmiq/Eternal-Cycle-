# Progression Rules

This section contains the canonical rules for multidimensional character development and later progression systems.

## Core Rules

- [Development System](DEVELOPMENT_SYSTEM.md) - shared capability model, earned growth, retained redevelopment, contextual assessment, and cross-track boundaries.
- [Physical Development](PHYSICAL_DEVELOPMENT.md) - embodied growth, body-specific capability, condition, physical transfer, and current-life rebuilding.
- [Skill Development](SKILL_DEVELOPMENT.md) - skill acquisition, Skill XP, mastery evidence, relearning, adaptive emergence, and bounded cross-tree translation.
- [Profession Development](PROFESSION_DEVELOPMENT.md) - integrated practice, professional judgment, credentials, institutions, responsibility, and reincarnational continuity.
- [Magical Development](MAGICAL_DEVELOPMENT.md) - magical access, control, capacity, affinity, authority, relearning, and system-specific embodiment.
- [Social and Leadership Development](SOCIAL_AND_LEADERSHIP_DEVELOPMENT.md) - communication, culture, relationships, authority, legitimacy, coordination, governance, and agency safeguards.
- [Species Development](SPECIES_DEVELOPMENT.md) - current-form traits, maturation, lifecycle, body-changing routes, ecology, and bounded reincarnational crossover.

## Current Scope

The Development System defines the philosophy shared by all Development Tracks. Physical, Skill, Profession, Magical, Social, Leadership, and Species Development are canonical; retained-development and cross-track systems remain separate roadmap tasks and are not implemented by this index.
