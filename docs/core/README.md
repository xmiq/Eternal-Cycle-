# Core Rules

The Core family contains the system-wide design constraints that every specialist owner must preserve. It establishes philosophy and boundaries rather than replacing narrower rules.

Repository-wide ownership, dependency, extension, and consumer metadata is maintained in the [Canonical Document Registry](../DOCUMENT_REGISTRY.md#core).

## Reading Order

1. [Design Philosophy](DESIGN_PHILOSOPHY.md) - Rule Zero, earned progression, fair mystery, meaningful death, emergent consequence, and cross-system design constraints.

## Boundary

Core principles constrain every completed phase but do not adjudicate a specialist claim when a narrower canonical owner exists. Campaign facts and live state remain outside this repository.
