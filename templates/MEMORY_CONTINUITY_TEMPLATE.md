## Validation Notes

- [ ] One Soul and one source Life own the memory's autobiographical origin.
- [ ] Current recall is represented through the receiving incarnation's Character Knowledge.
- [ ] Historical and mutable facts are stable references, not copied authorities.
- [ ] Player or GM access has not been treated as character recall.
- [ ] Recall has a valid route, provenance, and bounded representation.
- [ ] Missing detail remains Unknown or Requires Source Recovery.
- [ ] Familiarity, instinct, Echo, and memory remain distinct.
- [ ] No Skill, attribute, relationship, authority, or agency is granted by recall alone.
- [ ] The complete Affected Set is persisted and validated before durable narration.
