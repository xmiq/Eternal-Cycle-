# Template Index

Templates are storage-neutral, unpopulated contracts derived from Eternal Cycle canon. They identify required information, optional extensions, ownership, validation, and cross-references; they do not create campaign truth or replace the rules they cite.

Populate campaign instances only in an external Campaign Record. Reusable rules may enter `docs/` through ordinary repository governance; populated cross-campaign world-design assets belong in the separately deployed [GM Living Codex](../docs/gm-living-codex/README.md). A completed form gains no authority merely because it uses a repository template.

## Shared Use Rules

1. Read the listed canonical dependencies before populating a template.
2. Keep every stable identity distinct and use typed references rather than copied facts.
3. Use `Unknown`, `Not Yet Verified`, `Estimated`, `Requires Source Recovery`, or another canonical uncertainty state when evidence is missing.
4. Record each effect under one Authoritative Record Owner and one canonical mechanical owner.
5. Do not infer capability, authority, access, truth, or progression merely because a field exists.
6. Validate a populated record through the [Campaign Persistence Engine](../docs/persistence/README.md) before activation.
7. Use the [Coverage Map](TEMPLATE_COVERAGE.md) to confirm the authoritative module and avoid duplicate records.
